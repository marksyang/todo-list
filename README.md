# Simple Todo List Application

A lightweight, browser-based todo list application with localStorage persistence.

## Features

- Add new todo items
- Mark items as complete/incomplete
- Delete todo items
- Clear all completed items at once
- Data persistence using localStorage
- Responsive design for all screen sizes

## Files

- `dist/index.html` - Main HTML file
- `dist/style.css` - Styling for the application
- `dist/script.js` - JavaScript functionality

## How to Use

1. Open `dist/index.html` in any modern web browser
2. Type your todo item in the input field
3. Click "Add" or press Enter to add the item
4. Check the checkbox to mark an item as complete
5. Click "Delete" to remove an item
6. Click "Clear Completed" to remove all completed items

## Technical Details

- Built with vanilla JavaScript, HTML, and CSS
- No external dependencies
- Uses localStorage for data persistence
- Responsive design with Flexbox
- Cross-browser compatible

## Development

To modify the application:
1. Edit files in the `src/` directory
2. Run `cp src/* dist/` to copy changes to the distribution directory
3. Open `dist/index.html` in your browser to test

## Browser Support
